# Stardust Sandbox

## About the Project

This repository contains all source files used by the Stardust Sandbox static website, an open-source particle simulation game belonging to the sandbox game subgenre known as "falling sand games".

For more information about the project, visit the [Stardust Sandbox (legacy) repository](https://github.com/Stardust-Sandbox/stardust-sandbox-legacy.git). A new reimplementation of the game is currently under development and can be found in the [Stardust Sandbox (new version) repository](https://github.com/Stardust-Sandbox/stardust-sandbox.git).

The Stardust Sandbox static website is hosted on GitHub Pages and can be accessed at the following address: <https://stardust-sandbox.github.io>.
