# Stardust Sandbox

## Main Changes and Improvements

In this version, we focused on enhancing performance, fixing critical issues, and introducing new features to improve the overall user experience. Here are the highlights:

- Cache System for World Loading: A new caching system has been implemented, optimizing world loading and significantly reducing startup times.
- Updated Save File Management: Temporal states can now be loaded directly from save files, providing greater flexibility in continuing gameplay.
- Refined World Explorer: The selection index in the menu has been fixed, and the feature name has been adjusted to "WorldExplorer" for better consistency.
- Physical Materials Fix: An issue where fire did not pass through physical materials has been resolved, improving element interaction logic.

## Other Notable Improvements

- Directory Reorganization: The log directory has been moved to a more accessible location.
- Visual Asset Updates: New sprites for repository-related buttons have been added, enhancing the graphical interface.
- Code Optimization and Cleanup: Refactored code for improved readability and performance. Unnecessary console messages have been removed.
- General Repository Enhancements: Repository files were updated, outdated content removed, and redirects to the wiki documentation were added.

## Critical Fix for Windows DesktopGL

A major issue in the DesktopGL version for Windows has been fixed. Previously, a required DLL was missing in the installation directory, preventing proper execution. This has been resolved, ensuring all necessary files are included.

## Acknowledgments

We extend our thanks to the contributors and users who continue to support the development. If you encounter any issues, feel free to open a new issue in the repository.

Explore the new version and enjoy the improvements! 🎉
