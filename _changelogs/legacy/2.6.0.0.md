# Stardust Sandbox

Hello! This update introduces important improvements to the game's functionality and several internal adjustments that make the experience more stable, organized, and consistent.

During this development cycle, the main focus was on improving the project structure and refining some behaviors of the world simulation.

## What changed?

* The rendering system was integrated more efficiently into the game.
* Improvements to the internal behavior of components, making initialization simpler and more reliable.
* Adjustments to the vaporization and rainfall systems for more balanced behavior.
* Added enhanced support for points within the simulation world.
* Complete reorganization of the project's internal structure to facilitate future expansions.

## Important fixes

* Fixed an issue involving density interaction between liquids and mobile solids.
* Resolved a bug where some mobile solids could become stuck when contacting liquids.

## Internal improvements

In addition to visible changes, several parts of the code were reorganized and cleaned up to improve maintainability, stability, and readiness for new features in upcoming versions.

Thank you for following the project's development.
