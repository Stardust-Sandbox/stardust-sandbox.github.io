# Stardust Sandbox

Hello everyone, we hope you're all doing well!  

The **v1.2.2.0 update** aims to fix some minor issues identified in the last release. Unfortunately, these issues were causing the game to crash and close unexpectedly.  

**🛠 Fixes and Improvements**  

- The game is now limited to playing 32 sound effects simultaneously.  
- When using the "Erase Everything" and "Reload Simulation" buttons, the world will no longer destroy all elements but will remove them instead.  

Thank you for your patience. Enjoy the experience! 🧪
