# Stardust Sandbox

After countless hours of development, testing, and polishing, it’s finally time to celebrate a great milestone: the first stable release of Stardust Sandbox (v1.0.0.0) is now live and available to everyone! 🚀

## What is Stardust Sandbox?

For those new here, Stardust Sandbox is a falling-sand-inspired simulation game where every element is a block that interacts with others in unique and dynamic ways. Whether you want to experiment with physics, explore creative scenarios, or simply unwind in a mesmerizing sandbox, this game offers endless possibilities. 🌌

## What Makes This Release Special?

Version 1.0.0.0 represents the culmination of months of hard work and dedication. Here are some highlights:

### Stability and Performance

Fully tested for seamless gameplay on supported platforms: WindowsDX (Windows-only) and DesktopGL (Windows, MacOS, Linux).

Optimized rendering pipelines to deliver smooth performance.

### Expanded Interactions

New Element Types: Fresh blocks with unique properties to enrich the sandbox experience.

Improved Physics: Enhanced interactions for a more realistic and captivating simulation.

### Localization Support

Automatic language detection based on your system settings, with multiple languages supported from day one.

### Quality of Life Improvements

Updated UI for easier navigation.

Detailed tooltips and tutorials for new players.
