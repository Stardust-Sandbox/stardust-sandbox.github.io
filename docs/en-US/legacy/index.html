Summary

Introduction

A creative sandbox simulation inspired by classic falling-sand games.

Stardust Sandbox is an open-ended environment built around experimentation, physical interactions, and emergent behavior. Create structures, combine elements, trigger reactions, manipulate time, or simply watch the simulation unfold.

There are no predefined objectives. The world is yours to experiment with.

About

Stardust Sandbox is a physics-based sandbox where interactive elements follow their own properties and behaviors. By combining them, you can create systems, construct scenarios, experiment with reactions, or discover unexpected interactions.

The game is designed around curiosity rather than a fixed progression. Whether you want to build something elaborate or simply observe elements interacting with each other, there is no single way to play.

The project is available for Windows and Linux, with releases distributed through itch.io and Steam.

Features

  • Physics-based sandbox simulation
  • 90+ interactive elements with unique behaviors and interactions
  • Open-ended, non-linear gameplay
  • Pause and resume time at any moment
  • Retro-inspired pixel art
  • Day and night cycle
  • Customizable interface elements
  • Original soundtrack
  • Keyboard and mouse support

Get the Game

Stardust Sandbox is available for Windows and Linux.

The game can be downloaded from itch.io on a name-your-own-price basis. The Steam edition provides automatic updates and Steam integration.

The Project

Stardust Sandbox is an open-source project with its development history preserved across multiple generations of the game.

The current project is a reimplementation of the original game using C++ and SDL3. The original version, developed in C#, is preserved in the legacy repository.

Both projects are part of the Stardust Sandbox organization on GitHub.

Development

The current implementation continues the ideas established by the original Stardust Sandbox while providing a new foundation for future development.

The project's repositories contain the source code, development history, and supporting resources.
